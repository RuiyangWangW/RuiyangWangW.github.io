GAVEL: Graph World Models for Verified and Efficient Long-Horizon LLM Task Planning

Ruiyang Wang, Hao-Lun Hsu, Swarajh Mehta, Jiwoo Kim, Zhihao Dou, Miroslav Pajic

Submitted to ICRA 2027

LLM-generated robot plans often skip prerequisite steps or break embodiment constraints. GAVEL gives the LLM an explicit graph world model: it rolls each plan forward before execution, directly repairs failures whose fix follows from the action model, and sends only failures that need semantic reasoning back to the LLM. For multi-task instructions, it keeps beliefs over where unseen objects are and reorders the remaining tasks as the robot observes more.

  • 41.2% → 91.8% success on 100 long-horizon BEHAVIOR-1K tasks (Qwen3-8B)
  • 19.9% → 92.6% success on 500 multi-task instructions under partial observability
  • A 4B local model with GAVEL (75.2%) outperforms frontier hosted LLMs used alone (at most 38.6%)

Who to Trust in Multi-Robot Systems: Joint Robot and Object Hypothesis Trust Inference via Neural-Symbolic Cross-Validation

Ruiyang Wang, Hao-Lun Hsu, Haocheng Meng, Songqiao Xie, Miroslav Pajic

Submitted to RA-L

When robots share what they see, a compromised teammate can inject fake objects or hide real ones. NeST-Bayes infers which robots, and which reported objects, to trust using only whether robots' reports agree with each other: no prior trust, reputation, or side-channel signals. Each robot builds an ego-centric graph of agreements and contradictions, a heterogeneous graph attention network turns it into evidence, and Beta-distribution updates accumulate that evidence over time.

  • 96.4% / 97.0% robot / object precision against aggressive, optimized attackers
  • 97.3% / 97.7% precision in an occlusion-rich Webots warehouse with Spot robots, without retraining
  • Highest robot precision even when 40–50% of the team is adversarial (77.7% vs. at most 70.2%)

COMRES-VLM: Coordinated Multi-Robot Exploration and Search using Vision Language Models

Ruiyang Wang, Hao-Lun Hsu, David Hunt, Jiwoo Kim, Shaocheng Luo, Miroslav Pajic

Submitted to RA-L

A vision-language model acts as the team leader. Every 100 seconds it receives the merged team map, with the unexplored space cut into sensor-sized pieces behind each opening, and assigns every robot a piece, using a natural-language hint about the target when one is given. Between plans, each robot picks frontiers on its own while favoring its piece, so a late or missing plan never stalls the team.

  • Hint-guided search 11% faster than the strongest classical baseline (107 vs. 121 steps, p = 0.003)
  • 20–33% faster than Hungarian frontier assignment in exploration and hint-guided search
  • Reading the language hint finds the target 18% sooner than searching without it

Semantic Area Graph Reasoning for Multi-Robot Language-Guided Search

Ruiyang Wang, Hao-Lun Hsu, Jiwoo Kim, Miroslav Pajic

arXiv preprint

Instead of prompting a language model with raw maps or images, SAGR compresses the team's semantic occupancy map into a compact graph of rooms, where each node records its room type, frontiers, robots, and neighbors. An LLM reads this graph and the task (e.g. "find my jacket in the bedroom") and assigns robots to rooms; Hungarian matching and TSP ordering then handle frontier-level execution inside each room.

  • Up to 18.8% faster semantic search than the best baseline in large HM3D apartments
  • Fastest search at every environment scale while staying competitive on pure exploration
  • Compact prompts: under 500 tokens and about 2.5 s per coordination query

Neuro-Symbolic Deadlock Resolution in Multi-Robot Systems

Ruiyang Wang, Bowen He, Miroslav Pajic

L4DC 2025

Decentralized robots squeezing through a narrow passage can freeze in a deadlock that no single controller escapes. NSDR resolves deadlocks after they occur: an Active-Passive paradigm lets selected robots yield without creating new persistent deadlocks, and a Neural Logic Machine learns which robot should yield. Because the learned logic rules do not depend on team size, a model trained on small deadlocks generalizes to larger teams.

  • Trained on 2–5-robot deadlocks; generalizes to 8- and 10-robot and unseen asymmetric deadlocks
  • With 10 robots: 23% lower total arrival time than greedy and 12% lower than adaptive repulsive force
  • Resolves two-way traffic in which the repulsive-force baseline deadlocks again

Algorithms for Finding Compatible Constraints in Receding-Horizon Control of Dynamical Systems

Hardik Parwana*, Ruiyang Wang*, Dimitra Panagou (*equal contribution)

ACC 2024

Developed heuristics for maximal feasible subset selection in receding-horizon control using Lagrange multipliers to identify incompatible soft constraints. Achieved near-optimal performance at orders-of-magnitude lower computation cost than exhaustive methods.
